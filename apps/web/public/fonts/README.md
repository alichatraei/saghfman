# فونت وزیرمتن

برای اجرای آفلاین و سرعت بیشتر، فایل‌های زیر را در همین پوشه قرار دهید:

- `Vazirmatn-Regular.woff2`
- `Vazirmatn-Medium.woff2`
- `Vazirmatn-Bold.woff2`

دانلود از مخزن رسمی: <https://github.com/rastikerdar/vazirmatn/releases>

تا زمانی که این فایل‌ها اضافه نشده باشند، `app/globals.css` به‌صورت خودکار از نسخه CDN
استفاده می‌کند (به‌عنوان fallback در همان `@font-face`).
